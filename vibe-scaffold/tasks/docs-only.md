# Task: Docs Only

Gerar CLAUDE.md + docs de referencia para um projeto existente.

## Pre-requisitos
- Projeto ja tem codigo e/ou SPEC.
- Chief Architect faz entrevista rapida (rodadas 1-3).

## Execucao

1. **Chief Architect** coleta: nome, descricao, stack, atores, fluxos
2. **Doc Architect** gera CLAUDE.md + 3 reference docs
3. Revisao via checklist (apenas itens de docs)

## Output
`CLAUDE.md` + `docs/references/*.md`
