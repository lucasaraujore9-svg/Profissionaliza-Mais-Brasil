# Task: Break Only

Quebrar uma SPEC.md existente em issues numeradas.

## Pre-requisitos
- `docs/SPEC.md` deve existir na pasta do projeto.

## Execucao

1. **Issue Breaker** le a SPEC.md existente
2. Gera issues em `issues/*.md`
3. Gera `issues/README.md`
4. Revisao via checklist (apenas itens de issues)

## Output
Pasta `issues/` populada.
